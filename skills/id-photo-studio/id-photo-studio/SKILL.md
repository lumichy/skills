# ID Photo Studio（証明写真作成スキル）

任意の人物写真から、**AI画像編集（服装・姿勢・背景・照明のスタジオ補正）** と **Pythonによる精密画像処理（ミリ単位のトリミング・頭頂余白と顔比率の調整・L判/2L判面付けシート生成）** を組み合わせて、実用的な証明写真を作成するハイブリッドワークフローです。

特定のエージェントや固定の画像生成ツールに依存しない設計となっており、利用可能なツールを事前チェックして柔軟に動作します。詳細な規格サイズ表やAIプロンプトテンプレートは [presets.md](./references/presets.md) を参照してください。

---

## ワークフロー手順

### Step 1: 入力写真の確認・要件のヒアリング・利用可能ツールの事前チェック（必須）

1. **入力写真の視覚確認**:
   ユーザーから入力写真のパスまたは添付画像が提供されたら、まず画像読み取り機能（ファイルを視覚的に表示・認識するツール）で画像を読み込み、被写体の向き・服装・背景・髪型・余白の状態を確認します。
2. **必須確認事項のチェック（未指定時は必ず質問）**:
   スキル起動時、ユーザーの指示に以下の **「① 証明写真の用途／サイズ」** および **「② 印刷用紙サイズ（面付けシートの種類）」** が明示されていない場合は、勝手にデフォルト値で進めず、**必ず質問ツールまたはチャットメッセージでユーザーへ質問・確認してから** 次のステップへ進んでください。
   - **① 証明写真の用途・サイズ規格（必須確認）**:
     - `resume`: 履歴書・資格試験用（縦40×横30mm）
     - `mynumber` / `passport`: マイナンバー・パスポート用（縦45×横35mm）
     - `license`: 運転免許証用（縦30×横24mm）
     - `us_visa`: 米国ビザ用（縦51×横51mm）
     - `custom`: その他カスタムサイズ（縦×横mmを指定）
   - **② 印刷用紙サイズ・出力形式（必須確認）**:
     - `L`: L判（89×127mm）面付けプリントシート ＋ 単体データ
     - `2L`: 2L判（127×178mm）面付けプリントシート ＋ 単体データ
     - `none`: 単体デジタルデータのみ（印刷用シートは作成しない）
   - **③ 服装・表情の補正および背景色（必要に応じて併せて確認）**:
     - 補正パターン：
       - **パターンA**: 服装を着せ替え＋姿勢・表情も証明写真向け（口を閉じた正面向き）に補正
       - **パターンB**: 服装はそのまま維持し、背景・照明・姿勢のみ証明写真化
       - **パターンC**: **人物・顔の表情は一切変えず**、影（照明）・背景・服装のみ変更（※2段階ハイブリッド合成）
     - 背景色：白（`white`）、ライトブルー（`blue`）、ライトグレー（`gray`）など
3. **画像編集ツールの有無チェック（AI補正が必要な場合）**:
   服装の着せ替えや姿勢補正、首元の馴染ませなどAI画像編集が必要な場合、**現在のエージェント環境で「参照画像（元写真）を入力として受け取り、画像を編集・生成できるツール」が利用可能か** を確認します：
   - **利用可能なツールの例**:
     - エージェント組み込みの画像生成・編集ツール／サブエージェント
     - MCPサーバー経由の画像編集ツール
     - 環境変数にAPIキーが設定された画像編集対応SDK/CLI（`google-genai` / OpenAI Image API / ローカル画像生成API 等）
   - **【重要】適切な画像編集ツールが見つからない場合**:
     勝手に不完全な処理で進めたり失敗させたりせず、**作業を一時停止してユーザーに状況を伝え、以下のいずれで対応するか指示を仰いでください**：
     1. 画像編集用のツール／プラグイン（MCP等）の有効化、またはAPIキーの設定を行ってもらう
     2. 外部のAIツール等で着せ替え・背景処理のみ行ったベース画像をユーザーに用意してもらう
     3. AIによる着せ替え等は行わず、現在の写真の服装のまま **Pythonスクリプトのみ（`process_id_photo.py` の背景色置換 `--replace-bg` ＋ 規格トリミング ＋ 面付けシート生成）** で作成する

### Step 2: AIによる証明写真ベース画像の生成とハイブリッド合成

Step 1 で確認した利用可能な画像編集ツール（ツール・サブエージェント・MCP・API等）を使用し、スタジオ撮影風のベースポートレートを生成します。
（※入力写真がすでに正面向き・無地背景であり、AIによる服装変更やレタッチが不要な場合、またはPythonのみで処理する場合は、このStep 2をスキップしてStep 3へ進みます。）

- プロンプトの詳細は [presets.md のプロンプトテンプレート（パターンA / B / C）](./references/presets.md) から用途に合うものを選択して使用してください。
- **最重要ルール（本人性の維持とパターンCの2段階ハイブリッド合成）**:
  - 元の人物の目鼻立ち・輪郭・年齢感・ホクロ等の特徴（Facial Identity）を絶対に変えないよう強く指示します。
  - **【重要】パターンCが選択された場合（傾き補正＋2段階ハイブリッド合成）**:
    画像生成AI単体ではデコーダを通す過程で目鼻立ちや歯並び・髪型が微妙に変化し、逆にPython単体で顎の輪郭線に沿って切り貼りすると首元の境界や影が不自然になります。そのためパターンCでは必ず [composite_original_head.py](./scripts/composite_original_head.py) を用いて以下の手順で合成します：
    0. **事前処理（頭の傾き水平補正・標準3:4切り出し `--draw-grid` / `--level-and-crop`）**:
       元写真で被写体の頭が傾いている場合や複数人・全身のスナップ写真である場合は、まず `--draw-grid` で50px間隔の座標グリッド画像を作成して視覚確認し、向かって左目と右目の中心座標 `(x,y)` を読み取ります。続いて `--level-and-crop --left-eye x1,y1 --right-eye x2,y2` を実行すると、両目を結ぶ角度 $\theta = \text{atan2}(\Delta y, \Delta x)$ から傾きを自動算出して目が完全に水平になるよう回転補正し、瞳孔間距離を基準に正規化した `896×1200`（`3:4`）のベース画像を切り出します。
       ```bash
       # 1) 座標読み取り用グリッド画像の出力
       python ".agents/skills/id-photo-studio/scripts/composite_original_head.py" \
         --orig-crop "<INPUT_PHOTO>" --draw-grid --output "<SCRATCH_DIR>/grid.jpg"
       # 2) 両目座標から頭の傾きを水平補正し 896x1200 (3:4) に標準化切り出し
       python ".agents/skills/id-photo-studio/scripts/composite_original_head.py" \
         --orig-crop "<INPUT_PHOTO>" --level-and-crop \
         --left-eye 395,198 --right-eye 488,226 \
         --output "<SCRATCH_DIR>/leveled_crop.jpg"
       ```
    1. **Stage 1（元頭部の配置＋AIによる首元・輪郭の馴染ませ）**: 水平補正済みの切り出し画像（または `composite_original_head.py` で元画像の頭部をAIスーツ画像に配置した中間画像）を利用可能な画像編集AIに渡して、「頭部の位置・髪型・表情は変えず、顎の輪郭〜首元〜スーツと白シャツの襟の境界・照明・背景のみを自然なスタジオ証明写真に整える（Harmonize Neck, Suit & Lighting）」処理を行います。
    2. **Stage 2（顔内側の自動位置合わせ＋周波数分離ブレンド `--blend-inner-from`）**: Stage 1で首元・服装・背景が自然になった画像（`--ai-body`）に対し、水平補正済みの元画像（`--blend-inner-from`）から、高周波正規化相互相関（NCC）による自動位置合わせと非顔領域の事前マスキング付きGaussian Low-Pass色味補正を行い、**顔の内側（眉・目・鼻・口元・ほくろ）のみ**をソフト楕円マスクでブレンドします。これにより**「頭の傾き補正・首元・輪郭は100%自然」かつ「顔立ち・表情は100%元の写真そのまま」**が両立されます。
       ```bash
       python ".agents/skills/id-photo-studio/scripts/composite_original_head.py" \
         --blend-inner-from "<SCRATCH_DIR>/leveled_crop.jpg" \
         --ai-body "<AI_STUDIO_PORTRAIT>" \
         --inner-oval "462,498,128,118" \
         --output "<SCRATCH_DIR>/stage2_blended.jpg"
       ```
  - **【重要】パターンA（口を閉じた証明写真向けの表情に補正）が選択された場合（目元本人性100%ロック）**:
    歯が見えている笑顔の写真から口を閉じた表情（パターンA）をAIで生成すると、口元だけでなく目の開き方や二重幅までAIが変えてしまい別人のような顔になりがちです。そのためパターンAでも、`--level-and-crop` で水平補正した画像からAIで口を閉じたスタジオ画像を生成したあと、`composite_original_head.py --blend-inner-from` の楕円範囲を **目元〜鼻筋上部のみ（例：`--inner-oval "462,438,125,52"`）** に絞って元画像の目元をブレンドしてください。これにより **「目元・眉は100%本人のまま」かつ「口元は歯を見せない自然な閉口表情」** が実現できます。
  - 後続のPythonスクリプトでミリ単位のトリミングを行うため、**頭上および胸元に十分な余白（ヘッドルーム）を持たせたバストアップ構図**で出力させます。
  - 背景は影のない均一な単色（指定の背景色）にするよう指示します。
- 生成が完了したら、画像を読み込んで視覚確認し、顔立ちが本人と一致しているか・首元や輪郭に不自然な破綻がないかをチェックします。

### Step 3: Pythonスクリプトによる厳密な規格トリミングとプリントシート生成

AIで整えたポートレート画像（または元画像）に対して、[process_id_photo.py](./scripts/process_id_photo.py) を実行し、規格通りのピクセルサイズ・顔位置への切り出しとプリントシートの生成を行います。

```bash
python ".agents/skills/id-photo-studio/scripts/process_id_photo.py" \
  --input "<AI_PORTRAIT_OR_INPUT_PATH>" \
  --output-dir "<OUTPUT_DIR>" \
  --preset resume \
  --bg-color blue \
  --sheet-size L \
  --prefix "id_photo"
```

#### 主なオプション
- `--preset`: `resume` (40×30mm), `mynumber` (45×35mm), `passport` (45×35mm), `license` (30×24mm), `toeic` (40×30mm), `us_visa` (51×51mm), `custom`
- `--bg-color`: `white` (`#FFFFFF`), `blue` (`#D4E6F6`), `gray` (`#E6E8EA`), `sky` (`#C3DEF8`), または `#RRGGBB`
- `--replace-bg`: 入力画像の均一な背景をスクリプト側で指定の `--bg-color` に置き換える場合に付与します（AIを使わずローカル処理のみで背景色を変える場合や、1つのベース画像から複数背景色を作る際にも有効です）
- `--sheet-size`: `L`（L判 89×127mm / 127×89mm 自動判定）、`2L`（2L判 127×178mm / 178×127mm 自動判定）、または `none`
- `--head-top`, `--chin-bottom`, `--center-x`: 自動検出された頭頂・顎・顔中心の位置を手動で微調整するための正規化座標（`0.0`〜`1.0`）

### Step 4: 検証プレビューによる品質チェックと微調整（必須）

スクリプトを実行すると、以下の3ファイルが出力されます：
1. `<prefix>_<preset>_<H>x<W>mm.jpg`（Web出願・デジタル提出用の単体証明写真）
2. `<prefix>_<preset>_verification_preview.png`（頭頂ライン・顎ライン・中心線のガイド付き検証画像）
3. `<prefix>_<preset>_sheet_<L|2L>.jpg`（トンボ・50mm実寸確認スケール付きのコンビニ印刷用シート）

**検証手順**:
1. 必ず画像読み取り機能で `*_verification_preview.png` と `*_sheet_*.jpg` を表示して視覚的に確認します。
2. 検証画像の緑色の線（`Head Top`）が髪の毛の最上部付近に、赤色の線（`Chin`）が顎の先端付近に、青色の破線が顔の中心に揃っているかを確認します。
3. もし頭頂や顎の位置がずれている場合（顔が大きすぎる／小さすぎる、上の余白が広すぎる／狭すぎる場合）は、元画像における頭頂と顎のY座標比率（`0.0`〜`1.0`）を見積もり、`--head-top` と `--chin-bottom`（必要に応じて `--center-x`）を指定してスクリプトを再実行します。
   - 例: `python ".agents/skills/id-photo-studio/scripts/process_id_photo.py" ... --head-top 0.14 --chin-bottom 0.64`
4. ユーザーへ完了報告を行う際は、生成された単体写真・プリントシートのパスを提示し、**「コンビニ等でプリントする際は、拡大トリミングを防ぐため『フチあり印刷（縮小して全体を入れる）』を選択し、シート下部の50mmスケールを定規で測って実寸通りか確認してください」** と案内します。

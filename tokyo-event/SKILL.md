# Tokyo Event 查询技能

帮助用户查询指定日期在东京举办的各种活动。

## 使用场景

当用户想了解东京某日的活动时，使用此技能。活动类型包括：
- 演唱会、音乐节
- 展览、博物馆特别展
- 传统节日、祭典（花火大会、神社祭典等）
- 体育赛事
- 戏剧、舞台剧
- 其他活动

## 查询流程

### 1. 确认日期

首先确认用户要查询的日期：
- 如果用户已提供具体日期，直接使用
- 如果日期模糊（如"今天"、"下周六"），根据当前日期推算
- 如果未指定日期，询问用户

### 查询方法（通用）

对于以上所有优先网站：

1. **WebFetch** 访问网站首页
2. **提取所有相关活动**（关键！不要遗漏）

**⚠️ 重要：必须查询以下三类活动**

| 类型 | 说明 | 示例 |
|-----|------|------|
| 单日活动 | 仅在目标日期举办 | 5月31日当天 |
| 日期范围活动 | 目标日期在范围内 | 5月29日-31日、4月-5月31日 |
| 长期展览/活动 | 跨越目标日期 | 3月-6月、举办中-11月 |

**批量查询 prompt（必须使用此完整prompt）**：
```
请完整列出页面上所有活动，不要遗漏任何一个。需要包含：

1. [目标日期] 单日举办的活动（如：5月31日）
2. 日期范围包含 [目标日期] 的活动（如：5月29日-31日、4月-5月31日）
3. 正在举办中且 [目标日期] 仍在进行的长期展览/活动（如：3月-6月、举办中-11月）

请按以下格式列出：
- 活动名称（完整名称）
- 完整日期范围（开始日期-结束日期）
- 活动类型（展览/祭典/演唱会等）
- 地点/场馆

特别注意：
- 博物馆、美术馆的特别展通常是长期展览，必须列出
- "開催中"或"举办中"的活动需要查看结束日期
- 不要只搜索月份关键词，要完整扫描页面所有活动列表
```

3. **归类**：根据活动类型归入相应分类

### 3. 通用搜索

**重要：使用 `/web-search` skill（Brave Search API），不要用内置 WebSearch 工具。**

内置 WebSearch 有地区限制（US-only），对日语关键词效果差。使用 web-search skill 可以获得更好的结果。

调用方式：
```bash
/web-search "Tokyo events June 2026"
```

或通过 Skill 工具调用 web-search skill。

搜索策略：
1. **中英日三语搜索**：同一日期用多种语言搜索
2. **日期格式**：英文用 "June 2026"，日文用 "2026年6月"
3. **活动类型关键词**：concert, 演唱会, ライブ / exhibition, 展示会 / festival, 祭り

推荐搜索词示例：
- `Tokyo events June 2026` (英文)
- `東京 イベント 2026年6月` (日文)
- `Tokyo concert June 2026` (演唱会)
- `東京 展示会 2026年6月` (展览)
- `Tokyo festival June 2026` (祭典)

### 4. 补充信息来源

通用搜索时优先关注以下网站：
- **活动聚合**：eventr.jp, jleague.jp, timeout.com/tokyo
- **官方旅游**：gotokyo.org, japan.travel, tokyotokyo.jp
- **票务网站**：ticketboard.jp, eplus.jp, l-tike.com
- **演唱会**：japanconcerttickets.com, liquidroom.jp, shimamura.co.jp
- **场馆官网**：东京巨蛋、国立代代木竞技场、日本武道馆等

**搜索技巧**：
- 用日语关键词搜索：`ライブ`（演唱会）、`展示会`（展览）、`祭り`（祭典）
- 加 `site:` 限定网站：`site:eventr.jp 東京 6月`

### 5. 整理结果

将搜索到的活动整理为简洁列表格式。

## 输出格式

使用以下格式输出活动列表（按场地分组，便于用户规划行程）：

```
📅 东京活动 - YYYY年MM月DD日

📍 [场地名称]（区域）
| 活动名称 | 日期范围 | 状态 |
|---------|---------|------|
| [活动名称] | [完整日期范围] | ✅今日最终日/✅今日举办/🔄进行中/🆕今日开始 |

📍 [另一场地名称]（区域）
| 活动名称 | 日期范围 | 状态 |
|---------|---------|------|
| ... | ... | ... |
```

**状态标注说明**：
- ✅ 今日最终日 = 活动今天结束，最后参观机会（重点提醒！）
- ✅ 今日举办 = 仅今天举办的单日活动
- 🔄 进行中 = 活动跨越目标日期，仍在进行
- 🆕 今日开始 = 今天开始的活动

**按活动类型分类（可选）**：
```
🎵 演唱会/音乐
• [活动名称] - [日期范围] - [地点] - [状态]

🎨 展览（今日进行中）
• [活动名称] - [日期范围] - [地点] - 🔄进行中

🎨 展览（今日结束）
• [活动名称] - [日期范围] - [地点] - ✅今日最终日

🎌 祭典/节日
• [活动名称] - [日期范围] - [地点] - [状态]
```

如果某分类没有活动，省略该分类。

## 注意事项

- 时间格式：使用 24小时制，如 "19:00开演"
- 日期格式：必须显示完整日期范围，如 "5月29日-31日" 或 "4月4日-5月31日"
- 地点格式：包含场馆名和城市/区域，如 "东京ドーム (文京区)"
- 如果找到票务链接或官网，可在活动名称后添加链接
- 如果某活动信息不完整，用 "-" 表示缺失信息
- **长期展览标注**：对于跨越目标日期的长期活动，标注其状态：
  - ✅ 今日最终日 = 活动今天结束
  - ✅ 今日举办 = 仅今天举办
  - 🔄 进行中 = 跨越今天的活动
  - 🆕 今日开始 = 今天开始的活动

## 常见遗漏原因及预防

| 遗漏类型 | 原因 | 预防方法 |
|---------|------|---------|
| 长期展览 | 只搜索月份关键词 | 扫描页面所有活动列表 |
| 日期范围活动 | prompt不够精确 | 使用完整prompt模板 |
| 博物馆特别展 | 网站结构不同 | 特别关注博物馆、美术馆栏目 |
| "举办中"活动 | 忽略无明确开始日期的活动 | 查看"举办中"活动的结束日期 |
